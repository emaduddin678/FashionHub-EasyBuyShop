PHASE 2 — AUTH (Week 1-2)
Priority: High — needed for orders, wishlist, account
────────────────────────────────────────────────────────────

APIs needed:

POST /api/auth/register
     Body: { firstName, lastName, phone, email, password }
     Returns: { user, token }

POST /api/auth/login
     Body: { phoneOrEmail, password }
     Returns: { user, token }

POST /api/auth/logout
     Clears token

POST /api/auth/forgot-password
     Body: { phoneOrEmail }
     Returns: { message, otpSent }

POST /api/auth/verify-otp
     Body: { phoneOrEmail, otp }
     Returns: { resetToken }

POST /api/auth/reset-password
     Body: { resetToken, newPassword }

GET  /api/auth/me
     Returns: current user profile

Frontend changes:
- Replace mock login with real API call
- Store JWT token in httpOnly cookie or
  localStorage (cookie preferred for security)
- Create lib/api/auth.ts helper
- Add auth context or Redux authSlice
- Protect /account routes (redirect to login if no token)
- Update Header to show user name when logged in
- Remove mock user data from AccountDashboardPage

New files to create:
- lib/store/authSlice.ts
- lib/api/auth.ts
- middleware.ts (Next.js middleware for route protection)

Bangladesh payment gateways:

- Sandbox available for testing

NAGAD:

  Rocket, mobile banking
- Docs: sslcommerz.com/developer
